# Burning After Tea on an Empty Stomach

Strong tea or coffee before food can burn the empty stomach or the chest. This is a common everyday acidity trigger.

Have a biscuit or breakfast with the first cup, and switch to a weaker brew if it keeps happening.

See a doctor if empty-stomach burning is daily. Seek emergency care for crushing chest pain.
