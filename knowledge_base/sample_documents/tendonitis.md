# Tendonitis

Tendonitis is irritation of a tendon, such as the Achilles or wrist extensors. Pain is worse with the same repeated movement.

Relative rest, ice, and a gradual return to activity help. A clinician or physiotherapist can guide loading.

See a doctor if you heard a snap and cannot push off or lift the arm, which can be a tendon rupture.
