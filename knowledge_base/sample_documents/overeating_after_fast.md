# Discomfort After Eating a Lot When a Fast Ends

A large first meal after a long fast can cramp, burn, or bloat. The stomach has been empty and handles a smaller meal better.

Start with water and a modest simple plate, then eat more later if you still need it.

See a doctor if this keeps happening with vomiting. Seek emergency care for crushing chest pain or a rigid tummy.
